## Как загрузить сайт на GitHub Pages

1. Распакуйте архив. Откройте папку ilya-masha-site.
2. Создайте публичный репозиторий на GitHub, например ilya-masha.
3. В репозитории выберите Add file → Upload files. Перетащите содержимое папки: index.html, style.css, app.js, gallery.json, assets и этот README. Важно: index.html должен оказаться в корне репозитория, без дополнительной папки ilya-masha-site. Сохраните кнопкой Commit changes.
4. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), нажмите Save.
5. Через несколько минут GitHub покажет адрес сайта в Settings → Pages. Он открывается без ChatGPT.

## Что внутри

Мобильная версия, 22 фотографии и заглушки, интерактивный диван, Telegram @Mariiabb, покупка билетов РЖД и ссылка на Яндекс Карты.

Все фотографии, 3D-модель, просмотрщик и декодер находятся внутри архива. Сборка, ключи API и установка зависимостей не нужны.

Для запуска на компьютере нужен локальный веб-сервер: python3 -m http.server 8000 из этой папки, затем http://localhost:8000. Открытие index.html двойным кликом может блокировать загрузку 3D и галереи; после публикации на GitHub Pages это ограничение отсутствует.
