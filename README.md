# привет, дружок!
## Что внутри

Мобильная версия, 22 фотографии и заглушки, интерактивный диван, Telegram @Mariiabb, покупка билетов РЖД и ссылка на Яндекс Карты.

Все фотографии, 3D-модель, просмотрщик и декодер находятся внутри архива. Сборка, ключи API и установка зависимостей не нужны.

Для запуска на компьютере нужен локальный веб-сервер: python3 -m http.server 8000 из этой папки, затем http://localhost:8000. Открытие index.html двойным кликом может блокировать загрузку 3D и галереи; после публикации на GitHub Pages это ограничение отсутствует.
